# 높이 높이 · Higher Higher

![높이 높이](public/thumbnail.png)

> **무너지기 전까지, 더 높이.** 랜덤 블록을 하나씩 위로 쌓아 최고 높이 기록에 도전하는 물리 기반 밸런스 게임. 균형을 못 잡으면 탑이 실제로 기울다 **와르르** 무너집니다.

## 🎮 게임 소개

- 다음 블록이 **받침대(플레이 영역) 중심을 기준으로 판 전체를 좌우로 자동 왕복**합니다. 크레인처럼 진자 운동으로 움직이죠. 왕복 구간은 **탑이 어느 쪽으로 기울든 그걸 따라가지 않고 항상 판 좌우 끝까지 고정**되어 있어, **기운 탑의 반대편이나 바닥 위 어디에든** 마음대로 조준해 떨어뜨릴 수 있습니다.
- **탭 / 클릭 / 스페이스**를 누른 순간의 가로 위치에 블록이 **드롭**되어 낙하·안착합니다. 순수 **타이밍 게임**!
- 떨어진 블록은 **2D 강체 물리 엔진(matter.js)** 으로 실제 중력·마찰·회전(토크)에 따라 낙하·안착합니다.
- **잘 맞춰(중앙에) 놓으면 흔들림 없이 단단하게**, **치우치게 놓으면 기울다가** 균형을 잃고 무너집니다. 무너지면 게임 종료!
- 받침대(바닥)가 **넉넉하게 넓어** 초반 몇 층은 여유롭게 얹을 수 있습니다.
- 블록은 **최대 100개**. 무너지지 않고 100개를 다 쌓으면 **완주(클리어)** 입니다.
- 왕복은 **초반엔 아주 느긋**하고, 높이 올라갈수록 **완만하게** 조금 빨라질 뿐이라 타이밍이 빡세지 않습니다.
- 높이 올라갈수록 배경 하늘이 **새벽 → 한낮 → 성층권 → 우주**로 변합니다. 🌌

## ✨ 주요 기능

- 🎯 **자동 왕복 + 클릭 드롭** — 블록이 **판 전체(받침대 중심 기준 좌우 끝까지)** 를 스스로 스윙, 탭 한 번으로 그 순간 위치에 투하. 왕복 기준이 **탑 꼭대기가 아니라 고정된 필드 중심**이라 탑이 기울어도 판 어디에나 조준 가능. 데스크톱·모바일 동일.
- 🔮 **다음 블록 미리보기** — HUD의 **「다음」** 칸에 바로 다음에 나올 블록의 **모양 + 색 + 치수(가로 × 세로)**를 미리 보여줘 전략을 세울 수 있습니다.
- 📐 **블록 치수 표시** — 모든 블록에 **가로 × 세로 크기를 미터(m)로 라벨링**합니다. 단위는 HUD 높이 표시와 **같은 스케일(월드 px → m 변환 계수 재사용)**. **조준(왕복) 중인 블록**은 크고 또렷한 강조 라벨(예: `2.4 × 1.0`)로 떨어뜨리기 전에 크기를 알 수 있고, **이미 쌓인 블록**에도 각 블록 위에 작은 라벨을 얹습니다. 원은 지름 형식(예: `⌀1.2`). 라벨은 블록 색 위에서도 잘 보이도록 반투명 pill 배경 + 그림자로 대비를 주고, **카메라 줌·스크롤과 무관하게 화면 픽셀 기준 고정 크기**로 그려 너무 작아지면 자동 생략합니다(미니맵 안에는 표시하지 않음).
- 🧱 **다양한 랜덤 블록** — 정사각·직사각·와이드·사다리꼴·L자·T자·다각형·반원·원. 초반 30층 가까이는 **평평한 모양만** 나오고, **굴러가기 쉬운 원/반원은 탑 절반쯤(45층 이후)부터 드물게** 등장해 후반 긴장감을 담당합니다.
- ⚖️ **진짜 물리 밸런스** — 커스텀 캔버스 렌더링 + 고정 timestep 물리 시뮬레이션. 반발 0·높은 마찰·슬리핑 튜닝으로 **잘 놓으면 미동도 없이 단단**, 치우치면 여지없이 토플.
- 📈 **높이·블록 수 HUD** — 실시간 높이(m), 진행도(/100), 흔들림 경고. 탑이 자라면 카메라가 위로 따라 올라갑니다.
- 🗺️ **전체 탑 미니맵(오버뷰)** — 화면 오른쪽 패널에 **바닥(받침대)부터 현재 최상단까지 전체 탑을 등방(uniform) 축소**해 항상 보여줍니다. 가로·세로에 **하나의 공통 배율**(`min(패널가용폭/탑실제폭, 패널가용높이/탑실제높이)`)만 적용하는 **진짜 미니어처**라, 각 블록의 **실제 폭·높이·좌우 치우침·기울기가 비율 그대로** 작게 보입니다(넓은 블록은 넓게, 좁은 블록은 좁게, 삐뚤빼뚤한 탑은 삐뚤빼뚤하게 — 예전처럼 모두 같은 폭의 길쭉한 막대가 아닙니다). 블록은 **실제 색·실제 모양(footprint)** 으로 그려지고, 패널 폭은 탑의 실제 비율에 맞춰 **적응적으로 조금 넓어지거나 좁아지되**(짧고 넓은 탑은 넓게, 높은 탑은 좁게) 반응형 한계 안에서만 움직여 플레이·HUD·버튼을 가리지 않습니다. **메인 카메라가 보고 있는 구간은 뷰포트 박스**로 표시하고, 좁은 화면(모바일)에서는 숨겨집니다.
- 🏆 **도달 최고 높이 기록** — 매 프레임 **도달한 최고 높이(peak)** 를 추적해, 탑이 무너져도 **붕괴 직전에 도달했던 최고 높이**를 이번 판 점수로 확정합니다(붕괴 후 낮아진 높이가 아님). 그 peak가 `localStorage`의 최고 기록보다 크면 갱신하며, 결과 화면·스코어 카드도 peak(높이/블록 수) 기준으로 표시합니다. 게임오버·완주 시 **결과 스코어 카드**(탑 스냅샷 이미지)로 저장/공유.
- 🔊 **효과음 & 파티클** — Web Audio 기반 사운드, 안착 스파클, 붕괴 흔들림, 완주 컨페티.

## 🛠️ 기술 스택

- **React 19 + TypeScript** — UI / 상태
- **Vite 8** — 번들러 · 개발 서버
- **Tailwind CSS v4** — 다크 테마 UI
- **matter.js** — 2D 강체 물리(중력·충돌·마찰·토크). 렌더링은 물리 세계와 분리한 **커스텀 Canvas 2D**
- 서버·API 키 없이 **100% 클라이언트**에서 동작하는 정적 배포

## 🧪 검증

게임 상태 로직(블록 생성/난수, 자동 왕복 스윙 수식, 높이·점수 계산, 100개 제한, 무너짐 판정, 삼각형 제거, **도달 최고 높이(peak) 확정**, **블록 치수(bbox → m) 환산·라벨 포맷**)은 순수 함수로 분리해 자동 테스트합니다.

```bash
npm test   # 순수 로직 79개 단언 (tsx)
```

peak 로직은 별도 단언으로, **높이가 올랐다가 붕괴로 다시 내려가도 기록은 peak로 확정**되는지(붕괴 후 낮아진 값이 아님)를 검증합니다.

물리 플레이는 Playwright로 실제 구동을 확인했습니다 — 입력 없이도 블록이 좌우로 왕복하고(초반 스윙 주기가 이전보다 길어져 더 여유롭습니다), 탭한 순간의 위치에 안착하며, 다음 미리보기가 실제 다음 블록과 일치하고, 셰이프 풀에서 삼각형은 절대 나오지 않습니다. 또 **넓어진 받침대 위에서 중앙 정렬로 쌓은 탑은 몇 초를 기다려도 거의 흔들리지 않고**(위치·각도 drift 극소), 난이도를 낮췄어도 **일부러 치우치게 쌓으면 여전히 기울다 게임오버**로 이어집니다. 추가로 (a) 블록을 쌓다 **일부러 무너뜨렸을 때 결과·최고 기록이 붕괴 직전 peak로 확정·저장**되고(붕괴 후 낮아진 라이브 높이가 아님), (b) **오른쪽 미니맵에 전체 탑이 축소 표시되며 블록을 추가할수록 갱신**되는 것을 픽셀 단위로 확인했습니다. 또 (c) **조준 중인 블록의 강조 치수 라벨과 쌓인 블록들의 치수 라벨이 실제 캔버스에 렌더**되고 **HUD 「다음」 칸에도 치수가 표시**되는 것을 픽셀·DOM 텍스트로 확인했습니다.
